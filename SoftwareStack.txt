VeriSuri will be a Philippine-focused, PWA AI-powered fraud prevention PWA for iOS, Android, and desktop, built around our flagship feature: “Check Before You Pay.”

We'll use our own Python-trained scam detection model instead of Gemini or OpenAI APIs, retain your existing Vercel hosting, and use free/open-source tools wherever practical.

****** SOFTWARE STACK*************************
1. Frontend: React + TypeScript + Vite + Tailwind

Mobile: Installable PWA for iOS and Android

Backend: Python + FastAPI

AI: Custom scikit-learn hybrid scam detection engine

Database: Supabase PostgreSQL

Hosting: Vercel

Threat Intelligence: Google Web Risk + moderated community data

Long-term AI: Multilingual Transformers + ONNX offline inference

2. Final AI detection software
We should develop our own AI in two stages.
MVP
VeriSuri AI Engine V1 — Lightweight Hybrid Model

Python, scikit-learn, character-level TF-IDF, Logistic Regression, and a separate fraud-indicator rule engine.

4. Database structure
Our final initial database should contain these core tables.
Table	                                Purpose
profiles	                    User information and roles
scan_results	                Optional saved scam assessments
scam_reports	                Community-submitted reports
report_evidence	                Private attachments
reported_entities	            Reported URLs, payment identifiers, and other indicators
fraud_cases	                    Victim recovery case management
fraud_alerts	                Published scam advisories
moderation_actions	            Reviewer decisions and appeals
model_versions	                AI model versions and evaluation records
audit_logs	                    Sensitive administrative activity
Later, introduce entity_relationships, message_embeddings, and regional_statistics for advanced Scam DNA and geographic intelligence.

Use database Row-Level Security and strict access controls. Keep Supabase secret keys server-side, because those can bypass Row-Level Security.
